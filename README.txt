SECONDHAND SCORE - NETLIFY

1. Unzip this archive on your computer.
2. Open https://app.netlify.com/ and create/sign in to a free account.
3. For server-side API functions, use a Git-based deploy (recommended): put these files in a GitHub repository and choose Add new project > Import an existing project on Netlify. Select the repo and deploy. Publish directory is . and functions directory is netlify/functions (configured in netlify.toml).
4. In Netlify Site configuration > Environment variables, add EBAY_CLIENT_ID = your eBay Production App ID and EBAY_CLIENT_SECRET = the matching Production Cert ID. Scope must include Functions. Never put them in source code.
5. Trigger a new deploy after adding environment variables.
6. Open the site URL, search for Coach purse with a $150 budget and $15 maximum shipping, and verify live results.
7. If eBay returns 401, verify credentials and eBay OAuth access. If Browse API returns 403, verify eligibility/approval for the Browse API. Do not claim API functionality until real results display.

The server requests an OAuth application token and uses the eBay Browse search endpoint. Only listings with explicit shipping cost are ranked, which can exclude valid listings. The score is an illustrative heuristic.
